# Separate terminal Endings from non-terminal Ending unlocks

The Run model distinguishes terminal Endings from earned Ending unlocks.
Death, Quit Streaming, and Financial Ruin close a Run. `Made It` records its
time and causal audience event at 3,000,000 current Subscribers while allowing
play to continue. `She Cut You Off` has no implemented trigger.

Quit Streaming retains its persistent 72-game-hour Mood-zero risk clock.
Financial Ruin is instead an atomic total-debt check after every operation that
changes cash or an obligation. Death retains precedence when Health reaches 0.
This keeps physical survival, career success, and insolvency explicit without
inventing countdowns or Bond rules that the specification does not authorize.
