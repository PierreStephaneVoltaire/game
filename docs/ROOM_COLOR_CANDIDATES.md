# Shop items for existing room color swaps

This is an inventory for choosing future colors, not an implementation of room customization. Names and IDs come from `src/lib/data/shop-items.json`. The artwork targets are in `static/assets/room/room-front-bed.svg`, except the lamp, which is drawn in `RoomBackground.svelte`.

Items currently appear as separate images over fixed room artwork. A placement slot does not currently recolor that artwork. Each slot holds one item, so the bed's frame, mattress, blankets, and pillows cannot currently be equipped independently. Proposed colors are intentionally blank.

| Artwork    | Catalogue ID           | Item name            | Current placement or action          | Recolorable parts                      | Limitations                                                                       | Proposed colors |
| ---------- | ---------------------- | -------------------- | ------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------------- | --------------- |

Window elements and all cat-related items are excluded, including cat items placed on shelves. Items requiring entirely new room elements are also excluded. Item descriptions, actions, placement rules, artwork, and palette tokens have not been changed for this inventory.
